Genos — Command Threat Intelligence

A two-stage neural pipeline for real-time malicious command detection and MITRE ATT&CK technique attribution, powered by CodeBERT fine-tuned on shell and PowerShell corpora.

CodeBERT MITRE ATT&CK Deobfuscation 3-class verdict IEEE Research
How it works
Stage 1 — Gatekeeper A fine-tuned CodeBERT 3-class classifier outputs Benign / Suspicious / Malicious, aided by auxiliary ordinal-risk and non-benign binary heads. Stage 2 — Behavior Encoder A second CodeBERT model predicts the ATT&CK kill-chain stage and action type to generate MITRE technique attributions. Deobfuscation Up to 5 entropy-aware passes unwrap Base64, PowerShell char constructions, string concatenation, and hex escapes before inference. Rule engine Deterministic heuristics generate prior candidate masks that bias neural routing for high-confidence known patterns.
