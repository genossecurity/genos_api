Query parameter reference 3 parameters, one endpoint
ParameterDefaultWhat it does
commandRequiredThe command to analyze. Use curl’s --data-urlencode to preserve spaces and special characters.
tier2falseSet true to add a tier2 object with stage and stage_confidence. A benign result returns status: "skipped_benign" with null stage fields. 1 and 0 also work.
iocsOmittedUse all, or a comma-separated selection: {{ ioc_fields|join(', ') }}. Only selected keys are returned; empty arrays mean none found.

Invalid or unknown parameters return HTTP 400. Tier 2 and IOC extraction are independent options.
