Configuration and calibration remain separated into the Configuration tab so the pipeline stays readable.
InputAccepts raw command text through Flask endpoints.>
  • /scan/free is the no-key local demo endpoint.
  • /scan validates API keys and logs usage.
ObfuscationFlags evasive strings and decodes up to five layers.>
  • Checks [char], base64, FromBase64String, hex escapes, concatenation, and entropy above 5.2.
  • Scores both raw and decoded views when deobfuscation succeeds.
GatekeeperFine-tuned CodeBERT returns verdict probabilities.>
  • Labels are Benign, Context_Dependent exposed as Suspicious, and Malicious.
  • Returns confidence, probabilities, margin, model view, and thresholds.
RoutingDetermines whether behavior analysis is needed.>
  • Behavior runs for Suspicious/Malicious, low margin under 0.12, or suspicious signals.
  • If the route is false, behavior and full enrichment are skipped and the response contains minimal routing evidence.
has_tunnelinghas_base64_or_encoded_exechas_exfil_data_movementhas_sensitive_file_readhas_reverse_shell_pattern
BehaviorPredicts behavior stage and action tags.>
  • Input format: RAW, RESIDUAL, and optional FEATURES.
  • CodeBERT encoder with stage_head and action_head; fallback is heuristic_bootstrap.
EvidenceTurns parser, semantic, and rule signals into analyst context.>
  • parser.py, semantic_features.py, and rule_engine.py build fired rules, MITRE reasons, IOC summary, severity, and analyst hint.
ResponseFinal compact API object consumed by UI and callers.>
